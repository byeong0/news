## Claude AI Codex의 AGENTS.md 지원 시작

[TechBriefe](https://techbriefe.com/tech/ai) 보도 – 발행일: 2026-09-26

<!-- Broken Image Removed: Anthropic 로고 또는 코드 에디터 이미지 --> *(대표 이미지가 없을 경우 생략)*

[TechBriefe](https://techbriefe.com/tech/ai) - 발행일: 2026-09-26

### 요약
- Claude Code가 AGENTS.md 파일을 자동으로 읽을 수 있게 되었다는 업그레이드 발표.
- AGENTS.md는 OpenAI가 제안해 현재 여러 에이전트가 사용하는 크로스-에이전트 명령 파일 포맷.
- 이 기능은 Anthropic이 자사의 Claude Code v2.1.277(9월 18일 출시)에 도입했으며, 다양한 개발 환경에서 사용 가능.

### 주요 내용 및 시사점
- **기술적 의미**: Claude Code가 AGENTS.md를 네이티브 방식으로 지원하게 되어, 프로젝트 간 코딩 에이전트 통합성이 향상됨 ([mlllm.io](https://mlllm.io/articles/3242-claude-code-learns-to-read-agents-md-a-single-instruction-file-now-works-across-all-major-agents/?utm_source=openai)).
- **산업적 영향**: 다중 에이전트를 사용하는 환경에서 유지 보수 부담 감소, 협업 효율성 향상 예상 ([infoworld.com](https://www.infoworld.com/article/4224410/claude-code-now-also-accepts-instructions-in-openais-agents-md-format.html?utm_source=openai)).
- **향후 전망**: Amazon Bedrock, Google Vertex AI, Microsoft Foundry 환경에서는 아직 지원되지 않으며, 향후 확장 여부 주목됨 ([mlllm.io](https://mlllm.io/articles/3242-claude-code-learns-to-read-agents-md-a-single-instruction-file-now-works-across-all-major-agents/?utm_source=openai)).

## Hacktron 팀, Claude Opus 5로 OpenAI 직원 계정 제어 시연

### 요약
- 보안 업체 Hacktron의 연구진이 Anthropic의 Claude Opus 5를 활용해 버그 체인을 통해 OpenAI 직원의 ChatGPT/Codex 계정을 제어하고 내부 GitHub 리포지토리에 무해한 풀 리퀘스트 보내는 데 성공.

- **산업적 영향**: AI 에이전트의 보안 리스크 현실로 드러나며, 보안 대응 방식 변화 촉구.
- **향후 전망**: AI 기반 자율 보안 시스템 필요성 대두. 대응 표준화 및 대응 프레임워크 조속히 마련될 필요.
